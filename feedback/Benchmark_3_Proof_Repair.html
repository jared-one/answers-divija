The complete list

A factorisation can give every possible solution, but only if both directions are justified.

Useful starting idea

Rearranging to (x+y)(x−y−3)=10 is the decisive step. Do not stop after finding a few pairs.

The proof still needs

Choose every positive and negative ordered factor pair of 10, recover x and y, and explain why the resulting values are integers.

Try this first

If you present a complete list, can you explain why no ninth solution exists?

Reveal the model continuation
  1. Put u=x+y and v=x−y−3. Then uv=10.
  2. Enumerate the eight signed ordered factor pairs: (1,10), (2,5), (5,2), (10,1), (−1,−10), (−2,−5), (−5,−2), (−10,−1).
  3. Recover x=(u+v+3)/2 and y=(u−v−3)/2. Here u and v have opposite parity, so x and y are integers.
  4. Obtain the eight solutions: (−4,−6), (−4,3), (−2,−3), (−2,0), (5,−3), (5,0), (7,−6), (7,3). The factorisation is reversible, so they are both valid and exhaustive.
02 / 08   ·   ALGEBRA   ·   ALG3-02

When does equality hold?

The problem is not finished when the inequality is proved; equality is a second obligation.

Useful starting idea

Look for a known inequality matching the powers 2 and 3 rather than expanding a high-degree expression.

The proof still needs

Apply Cauchy–Schwarz to a3/2 and a1/2 (and similarly for b,c). Then track zero coordinates.

Try this first

What goes wrong if you only write a=b=c?

Reveal the model continuation
(a²+b²+c²)² ≤ (a³+b³+c³)(a+b+c) = a³+b³+c³.

Cauchy–Schwarz applies because a,b,c are non-negative. Equality holds when (a3/2,b3/2,c3/2) and (a1/2,b1/2,c1/2) are proportional.

Every positive coordinate must then have the same value. If there are k positive coordinates, each is 1/k, where k=1,2,3. Hence the equality cases are all permutations of (1,0,0), (½,½,0), and (⅓,⅓,⅓). Direct substitution verifies every case.

03 / 08   ·   GEOMETRY   ·   GEO3-01

Reflecting the orthocentre

A complicated drawing is not a substitute for one justified cyclic-angle statement.

Useful starting idea

A reflection preserves angles; a circumcircle claim must be justified by the converse of a circle theorem.

The proof still needs

Work with the reflection of H across BC only. Prove the relevant opposite angles sum to 180°, then relabel.

Try this first

Which exact four points form the cyclic quadrilateral, and why?

Reveal the model continuation
  1. Let H′ be the reflection of the orthocentre H in BC. Since BH ⟂ AC and CH ⟂ AB, ∠BHC = 180°−∠BAC.
  2. Reflection fixes B,C and preserves angle magnitudes, so ∠BH′C=180°−∠BAC.
  3. In an acute triangle H lies inside ABC, so H′ and A are on opposite sides of BC. The opposite angles of ABH′C are supplementary; by the converse cyclic-quadrilateral theorem, H′ lies on the circumcircle of ABC.
  4. Use the same proof for reflections in CA and AB.
04 / 08   ·   GEOMETRY   ·   GEO3-02

Two lemmas, one conclusion

When a problem asks for two parts, each part should contribute a distinct fact to the final claim.

Useful starting idea

Name your triangles before writing ratios, and check the correspondence of their vertices.

The proof still needs

Prove a product identity using cyclic angles. Independently obtain a ratio identity using AB parallel CD.

Try this first

Did you use the same vertex correspondence twice when two different correspondences were needed?

Reveal the model continuation
  1. From the cyclic quadrilateral, the relevant inscribed angles give △PAB ∼ △PDC, hence PA·PC = PB·PD.
  2. If AB ∥ CD, then △PAB ∼ △PCD. Thus PA/PC = PB/PD = r > 0.
  3. Substitute PA=r·PC and PB=r·PD into the first relation: r·PC²=r·PD². Since the lengths and r are positive, PC=PD and then PA=PB.
05 / 08   ·   NUMBER THEORY   ·   NT3-01

An exact power of two

Small examples suggest a pattern, but the phrase “for every n” asks for a universal argument.

Useful starting idea

Track precisely how many factors of 2 appear in the product.

The proof still needs

Try comparing Pn+1 with Pn, or factor (2n)! into odd and even terms.

Try this first

Can you explain in one sentence why the argument covers every positive integer?

Reveal the model continuation

Fast direct proof. Write

Pn = (2n)!/n! = (2·4·…·2n)(1·3·…·(2n−1))/n!.

The even factors contribute 2nn!, so after cancellation:

Pn/2n = 1·3·5·…·(2n−1),

which is an odd integer for every positive n.

Induction alternative. With Qn=Pn/2n, show Q1=1 and Qn+1=(2n+1)Qn. Oddness is preserved.

06 / 08   ·   NUMBER THEORY   ·   NT3-02

How large can the gcd be?

A possible gcd and a proven gcd are different things.

Useful starting idea

A short linear combination restricts what a common divisor can be. The residue cases show when the upper possibility occurs.

The proof still needs

Set d=gcd(n²+n+1,2n+1). Use 4 times the first expression minus the square of the second.

Try this first

Have you proved both an upper restriction and the case where equality is attained?

Reveal the model continuation
4(n²+n+1) − (2n+1)² = 3.

Since d divides both original expressions, d divides 3, so d is 1 or 3.

If n≡1 (mod 3), both expressions are divisible by 3, giving d=3. For n≡0 or 2 (mod 3), 2n+1 is not divisible by 3, giving d=1. The three residue classes are exhaustive, including negative integers.

07 / 08   ·   COMBINATORICS   ·   COMB3-01

The hidden consecutive block

A pigeonhole proof must specify the objects, the boxes, and the nonempty block.

Useful starting idea

Partial-sum residues convert a “some consecutive entries” problem into equal remainders.

The proof still needs

Create S0=0 and Sk=a1+…+ak, for k=1,…,n.

Try this first

Why are there n+1 prefix sums, and why does i<j guarantee a nonempty block?

Reveal the model continuation

The n+1 prefix sums S0,S1,…,Sn occupy only n residue classes modulo n. Thus some Si and Sj have the same remainder, with 0≤i<j≤n.

Sj−Si = ai+1+…+aj ≡ 0 (mod n).

Because i<j, the block contains at least one term. That last sentence closes the proof.

08 / 08   ·   COMBINATORICS   ·   COMB3-02

Ten numbers, or nine?

A counterexample at nine proves sharpness; it does not establish the claim for ten.

Useful starting idea

Separate the two obligations: prove every ten-term sequence works, then construct a nine-term exception.

The proof still needs

For each position i, record the longest increasing and decreasing subsequence lengths ending there.

Try this first

Which part proves ten are enough, and which proves nine are not enough?

Reveal the model continuation

Let pi and qi be the lengths of the longest increasing and decreasing subsequences ending at position i. If no length-4 subsequence exists, each pair (pi,qi) is among only 3×3=9 possibilities.

Ten distinct terms force two positions i<j with the same pair. If xi<xj, an increasing subsequence at i extends to j, so pj>pi; if xi>xj, similarly qj>qi. Contradiction.

3, 2, 1,  6, 5, 4,  9, 8, 7

This nine-term arrangement avoids both types of length 4: increasing subsequences choose at most one number per block, and decreasing ones stay within a single block.

One reusable proof check: For a “find all” problem, prove necessity and sufficiency. For a maximum/minimum, prove the bound and a construction. For induction, prove the base and the transition. For geometry, name the theorem and establish its hypotheses.
