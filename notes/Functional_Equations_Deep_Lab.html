Functional equations: from first steps to BMO Q6

From f(0) to integer-valuedness, discrete differences, injectivity, surjectivity and a complete proof of the 2019 good-functions problem.

01 / ESSENTIALS

What does a functional equation ask?

A functional equation asks you to find every function satisfying a stated relation for every permitted input. It is a classification problem, not simply a substitution exercise.

Write the domain and codomain before starting. The same displayed equation can have different solutions over ℤ, ℚ, ℝ or the positive integers. A candidate formula must satisfy every condition, and you must rule out any other function.

Example: if f:ℤ→ℤ satisfies f(n+1)=f(n)+3 and f(0)=2, repeated steps suggest f(n)=3n+2. For negative n, work backwards using f(n)=f(n+1)−3. Then substitute your formula into both conditions. Uniqueness follows because each integer is reachable from zero by finitely many ±1 steps.

What if f(0) is not given?

The same recurrence f(n+1)=f(n)+3 allows the entire family f(n)=3n+c with arbitrary integer c. Without f(0), you cannot choose the intercept.

02 / STANDARD OPENINGS

Substitute zero, equality and negatives

If the domain includes zero, substitute x=0 or y=0 first. In symmetric equations try x=y and y=−x. When the equation includes f(x+y), compare (x,y), (x,0), and (0,y). These substitutions often reveal f(0), parity and injectivity.

Do not substitute a value outside the domain. If the problem states x,y>0, plugging in zero is invalid.

f(x+y)=f(x)+f(y)  ⇒   f(0)=0,  f(−x)=−f(x).

For f:ℤ→ℤ with the additive identity, first set x=y=0 to obtain f(0)=2f(0), hence f(0)=0. Then x+(-x)=0 gives f(-x)=-f(x). Induction yields f(n)=nf(1) for positive integers, and the negative case follows by oddness.

03 / PROPERTIES

Injective, surjective, bijective

Injective: f(a)=f(b) forces a=b. Surjective: every target value has a preimage. Bijective: both hold. A proof should not simply announce that f is injective because the equation “looks one-to-one”.

If a functional equation yields f(x)=f(y)⇒x=y, that proves injectivity. If it yields f(x−c)=t for every target t, with an allowed x, that may prove surjectivity. Check domains, not just the shape of the formula.

Why codomain matters

f(n)=2n from ℤ to ℤ is injective but not surjective (odd integers are not outputs). The same rule from ℤ to 2ℤ is bijective. The codomain changes the answer to “surjective?”.

04 / METHOD

Compare two evaluations of the same term

A common technique is to compute one expression in two different ways, then subtract. For example, if f(x+y)=f(x)+f(y)+2xy over integers, set g(x)=f(x)−x². Since (x+y)²=x²+2xy+y², we find g(x+y)=g(x)+g(y). Hence g(n)=cn, and f(n)=n²+cn.

Always substitute the candidate into the original equation: (x+y)²+c(x+y)=x²+cx+y²+cy+2xy. This checks sufficiency.

05 / INTEGER FUNCTIONS

Differences, periodicity and discrete calculus

For a function on integers, f(n+1)−f(n)=c implies f(n)=cn+b. More generally, if the second difference is zero, then the first differences are constant.

f(n+1)−2f(n)+f(n−1)=0  ⇒  f(n)=an+b.

Proof: let d(n)=f(n)−f(n−1). The equation gives d(n+1)=d(n), so d is constant. Summing constant differences reconstructs the affine function. The equation holds for all integer n, so extend in both directions.

If f(n+2)=f(n), values are determined by parity: one value on even inputs, another on odd inputs. Do not assume periodicity implies constancy.

06 / RESTRICTIONS

Integer-valuedness and parity

Suppose an argument gives f(m,n)=((k+1)m+(1−k)n)/2 for all integers m,n. You cannot stop there: because outputs must be integers for every choice of m,n, take (m,n)=(1,0) and (0,1). This forces k odd. Rewriting k=2r+1 makes the formula transparently integer-valued.

Checking a function with one or two easy inputs is useful for narrowing parameters, but it does not verify the equation for every input. Perform a symbolic substitution at the end.

07 / AUTHENTIC BMO DEEP DIVE

The 2019 “good functions” problem

Consider the official 2019 BMO1 Question 6 at the original paper. Read its two equalities first; the aim is to classify every integer-valued function of two integers.

  1. Compress the dimension. Set g(t)=f(t,−t). Use the first equality to express 2f(m,n) through g(m−n), m and n.
  2. Use the second equality. Substitute the expressions for f(m+1,n) and f(m,n+1), obtaining a second-difference relation for g.
  3. Conclude g is affine. The second difference vanishes for every t∈ℤ, hence g(t)=kt+b. The first relation at (0,0) gives b=0.
  4. Use the integer codomain. The formula for f must take integer values at every integer pair, forcing k odd.
  5. Check the entire family. Substitute into both original equalities and confirm the result for all integers.
Complete model derivation (read only after attempting)

Start with the published relation, which has one equality linking f(m,n) to f(m−n,n−m) and another linking it to shifted inputs. Define g(t)=f(t,−t). The first equality becomes 2f(m,n)=g(m−n)+m+n.

Applying the second equality and substituting this expression yields g(t+1)+g(t−1)=2g(t): consecutive differences are constant. Hence g(t)=kt+b for all integers t. Evaluating the first identity at (0,0) shows b=0; also g(2t)=2g(t), consistently.

Therefore f(m,n)=[k(m−n)+m+n]/2. It is an integer for every integer m,n exactly when k is odd, say k=2r+1. Thus f(m,n)=(r+1)m−rn for any integer r. Direct substitution verifies both original equalities, completing necessity and sufficiency. You can work backwards through this solution in the dedicated Functional Equations course.

The central method has five parts: reduce, compare, prove a general form, restrict parameters, and verify.

08 / BEYOND THE EXAM

Advanced structural thinking

Iteration: use f(f(x)) carefully; prove f(x) lies in the domain. Symmetry: compare P(x,y) and P(y,x) to eliminate unknown terms. Injectivity trigger: if f(A)=f(B), look for an equation that forces A=B. Surjectivity trigger: if a target appears linearly on one side, solve for a preimage.

Warning about Cauchy over ℝ: f(x+y)=f(x)+f(y) does not automatically imply f(x)=cx for all real x without regularity assumptions. For integer input it does; over real numbers, continuity, measurability or monotonicity can force linearity. This distinction matters at advanced levels.

Recommended progression: master the integer-domain classification, then try equations involving symmetry, nested f, parity or rational inputs.

09 / PRACTICE LADDER

Exercises with graded hints

Attempt each on paper. In every answer, state necessity and sufficiency.

  1. F1 (entry): f:ℤ→ℤ, f(n+1)=f(n)+5, f(0)=−2. Find f.
  2. F2 (entry): f:ℤ→ℤ, f(x+y)=f(x)+f(y), f(1)=−3. Find f.
  3. F3 (bridge): f:ℤ→ℤ, f(x+y)=f(x)+f(y)+4xy and f(1)=5. Find f.
  4. F4 (bridge): f:ℤ→ℤ, f(n+2)=f(n), f(0)=4, f(1)=−1. Find all values.
  5. F5 (stretch): f:ℤ→ℤ, f(m+n)+f(m−n)=2f(m)+2f(n), with f(0)=0 and f(1)=1. Determine whether a unique f exists.
Solutions and rigorous checks
  1. f(n)=5n−2. Prove in both positive and negative directions by the recurrence and check f(0).
  2. f(n)=−3n using integer additivity and negative arguments.
  3. Put g(n)=f(n)−2n²: g is additive, g(1)=3; f(n)=2n²+3n. Verify by expansion.
  4. f(even)=4 and f(odd)=−1; f(n+2)=f(n) propagates both parity classes in both directions.
  5. f(n)=n² is a solution. More generally integer quadratic identity implies f(n)=n² by induction from f(0)=0,f(1)=1: take m=n, n=1 to get f(n+1)+f(n−1)=2f(n)+2. With initial values and f(-1)=f(1) from m=0, the recurrence determines all integers. Substitution verifies.
EXTENDED WORKSHOP 01 / READ, PROVE, TRANSFER

The zero input is usually the first experiment

When to reach for this. The input 0 can isolate a constant, test whether an unknown expression vanishes and establish a neutral element.

Complete worked argument

Suppose f:ℤ→ℤ satisfies f(x+y)=f(x)+f(y)+7 for all integers. Let g(x)=f(x)+7. Then g(x+y)=g(x)+g(y). In particular g(0)=0, so f(0)=−7. Every additive integer function has the form g(n)=cn, so f(n)=cn−7 for some integer c. Conversely any such f satisfies the equation.

The tempting wrong moveDo not assume f(0)=0 without using the equation; the extra constant changes it.

Transfer question

Determine all f:ℤ→ℤ with f(x+y)=f(x)+f(y)+3 and f(1)=2.

Show a complete answer and proof

Setting x=y=0 gives f(0)=−3. Put g(n)=f(n)+3. Then g(x+y)=g(x)+g(y) and g(1)=5. Thus g(n)=5n for every integer n, including negatives. Therefore f(n)=5n−3. Direct substitution verifies the original equation.

EXTENDED WORKSHOP 02 / READ, PROVE, TRANSFER

Prove injectivity by forcing equal inputs

When to reach for this. A standard way to show f is injective is to assume f(a)=f(b), then use the functional relation to deduce a=b.

Complete worked argument

If f:ℝ→ℝ obeys f(x+y)=f(x)+f(y) and f(1)=1, the relation alone does not imply f(x)=x for all real x: additive noncontinuous functions exist. But the relation does imply f(q)=q for all rational q by repeated addition and division. To prove injectivity additionally one might need positivity, monotonicity, boundedness or a special structural identity.

The tempting wrong moveA functional equation on ℤ and the same equation on ℝ can have radically different classifications. Always copy the domain into the first line.

Transfer question

Assume f:ℝ→ℝ is additive and strictly increasing. Prove f is injective.

Show a complete answer and proof

Suppose f(a)=f(b). If a<b, strict monotonicity gives f(a)<f(b), contradiction. If b<a, the reverse inequality gives a contradiction. Thus a=b. This uses the additional strict monotonicity, not additivity alone.

EXTENDED WORKSHOP 03 / READ, PROVE, TRANSFER

Establish surjectivity with a genuine preimage

When to reach for this. Surjectivity means every target value is hit, and many equations allow one to construct the needed input.

Complete worked argument

Take f:ℤ→ℤ given by f(n)=n+3. For any requested integer y, choose x=y−3, itself an integer. Then f(x)=y. Thus f is onto ℤ. Compare g(n)=2n: its image omits odd integers, so it is not surjective onto ℤ. The codomain matters.

The tempting wrong moveFinding three outputs is not enough to prove surjectivity over an infinite codomain.

Transfer question

Prove h:ℝ→ℝ, h(x)=3x−7 is surjective, and give its inverse.

Show a complete answer and proof

For any y in ℝ, take x=(y+7)/3. Then h(x)=3(y+7)/3−7=y. Hence surjective. Solving y=3x−7 gives h⁻¹(y)=(y+7)/3. Injectivity follows because 3x−7=3z−7 implies x=z.

EXTENDED WORKSHOP 04 / READ, PROVE, TRANSFER

Replace a quadratic defect with an additive equation

When to reach for this. Whenever f(x+y) differs from f(x)+f(y) by a simple polynomial, subtract a matching polynomial.

Complete worked argument

For integers x,y, the identity (x+y)²−x²−y²=2xy suggests trying g(n)=f(n)−n² when f(x+y)=f(x)+f(y)+2xy. Then g is additive. Integer additivity forces g(n)=cn, hence f(n)=n²+cn, where c is any integer. Substituting verifies every member of the family.

The tempting wrong moveOn real numbers, additive g need not be linear without regularity. Do not silently transfer the integer classification to all real inputs.

Transfer question

Classify integer f satisfying f(x+y)=f(x)+f(y)+4xy and f(1)=3.

Show a complete answer and proof

Set g(n)=f(n)−2n². Then g(x+y)=g(x)+g(y). Since g(1)=1, integer additivity gives g(n)=n. Therefore f(n)=2n²+n. Verify expansion: 2(x+y)²+x+y=2x²+x+2y²+y+4xy.

EXTENDED WORKSHOP 05 / READ, PROVE, TRANSFER

A recurrence can determine all integers, including negative ones

When to reach for this. Forward recurrence alone often gives positive values, but a true ℤ-domain solution also requires backward iteration.

Complete worked argument

Suppose f(n+1)=f(n)+2n+1 for every integer n, and f(0)=0. We recognise (n+1)²−n²=2n+1. Thus h(n)=f(n)−n² satisfies h(n+1)=h(n), so h is constant on all integers. Since h(0)=0, f(n)=n² for every n∈ℤ. Direct substitution confirms the recurrence for negative n as well.

The tempting wrong moveA proof by induction on n≥0 does not automatically cover negative input; the backwards recurrence or a difference invariant is needed.

Transfer question

For all integer n, f(n+1)=f(n)+3n²+3n+1 and f(0)=2. Find f.

Show a complete answer and proof

The difference (n+1)³−n³ is 3n²+3n+1. Hence f(n)−n³ is constant on ℤ; at n=0 that constant is 2. Thus f(n)=n³+2 for all integers. Verify by direct substitution.

EXTENDED WORKSHOP 06 / READ, PROVE, TRANSFER

Use two inputs to force a contradiction or a classification

When to reach for this. Comparing f(x+y) and f(y+x), f(f(x)) and f(f(y)), or f at two decompositions can eliminate unknown pieces.

Complete worked argument

If f:ℤ→ℤ obeys f(x+y)=f(x)+y and f(0)=5, there is an immediate decomposition x=0,y=n giving f(n)=5+n. The same formula verifies the full identity. More generally, when one input makes the unknown function at a fixed point, try it before elaborate substitutions.

The tempting wrong moveDo not derive an identity under the assumption x≠0 and later apply it at x=0 without checking the excluded case.

Transfer question

Suppose f(x+y)=f(x)+3y for all integers x,y. Find every possible f.

Show a complete answer and proof

Set x=0 to get f(y)=f(0)+3y. Let c=f(0), any integer. Then f(n)=3n+c. Substitution gives f(x+y)=3(x+y)+c and f(x)+3y=3x+c+3y, equal. Every c is valid.

EXTENDED WORKSHOP 07 / READ, PROVE, TRANSFER

The 2019 “good functions” strategy: identify the hidden parameter

When to reach for this. For a difficult functional equation, the first objective is to discover the invariant parameter and show it is integral.

Complete worked argument

For the 2019 BMO1 “good functions” problem, write f(m,n) using the normalisation and the recursive relation. Evaluate small special integer pairs until a one-parameter affine candidate emerges: f(m,n)=(r+1)m−rn for some integer r. It is not sufficient to spot the pattern: every candidate must satisfy the original relations and every possible good function must be forced into this form. Follow the scored 2019 companion for the full complete derivation, rather than trusting the initial numerical pattern.

The tempting wrong moveAvoid treating a guess from three numerical inputs as proof that the function is affine. The essential work is proving an identity for arbitrary integer arguments from the given rules.

Transfer question

Verify for any integer r that F(m,n)=(r+1)m−rn is integer-valued and satisfies F(m,m)=m.

Show a complete answer and proof

For integer m,n,r, F(m,n) is integer. At equal inputs, F(m,m)=(r+1)m−rm=m. It is linear in (m,n) and meets the diagonal identity. For a full classification, you must still verify each further functional rule from the original paper, not assume these two facts suffice.

EXTENDED WORKSHOP 08 / READ, PROVE, TRANSFER

Beyond BMO1: when to learn optional real-function regularity

When to reach for this. Long-term development can introduce continuous or monotone additive functions and techniques useful internationally, but these are not required before this examination.

Complete worked argument

For an additive f:ℝ→ℝ with f continuous at 0, use rational approximation: for rational q, f(q)=qf(1). Given x and rational qₙ→x, continuity implies f(x)=lim f(qₙ)=lim qₙ f(1)=xf(1). Hence f(x)=cx, now rigorously for all real x. Conversely every f(x)=cx is additive and continuous.

The tempting wrong moveIt is false that additivity by itself gives f(x)=cx for all real x. Continuity or another regularity assumption is genuinely used.

Transfer question

Show that additive f:ℝ→ℝ with f(x)≥0 whenever x≥0 must be linear.

Show a complete answer and proof

If x<y, y−x>0 so f(y)−f(x)=f(y−x)≥0. Thus f is nondecreasing. For rational q, f(q)=qf(1); approximate a real x from below and above by rationals pₙ≤x≤qₙ with both→x. Monotonicity squeezes f(x) between pₙf(1) and qₙf(1), so f(x)=xf(1).
