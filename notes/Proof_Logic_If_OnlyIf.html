If, only if, and complete proofs

A full logical toolkit: arrows, necessity, sufficiency, contrapositives, quantified statements, exhaustive cases and six worked exercises.

01 / PROOF LANGUAGE

If means a guarantee

Let P be “you finish your homework” and Q be “you receive cake”. Q if P means P⇒Q: completing homework is sufficient to guarantee cake. It does not say cake is impossible for any other reason.

“Q if P” means P ⇒ Q.

In a theorem, “if an integer is divisible by 6, then it is even” has P = divisible by 6, Q = even. Prove the arrow by writing n=6k=2(3k).

One statement is not the converse

The converse “if n is even, then n is divisible by 6” is false: n=2 is a counterexample. A correct implication does not automatically make its converse correct.

02 / NECESSITY

Only if means a requirement

“You receive cake only if you finish homework” means getting cake requires homework. It is the reverse arrow: Q⇒P. Homework is necessary for receiving cake, but finishing homework alone does not guarantee cake.

“Q only if P” means Q ⇒ P.

P if Q

Q ⇒ P. The condition following “if” is enough.

P only if Q

P ⇒ Q. The condition following “only if” is required.

Mnemonic: to have P, you must have Q; therefore assume P and prove Q.

Common translation trap

“n is divisible by 6 only if n is divisible by 3” translates to 6|n⇒3|n. Proving 3|n⇒6|n is the wrong direction.

03 / TWO DIRECTIONS

If and only if = both directions

“P if and only if Q” (abbreviated P iff Q) means P⇒Q and Q⇒P. You must establish necessity and sufficiency; both statements are part of the problem.

P ⇔ Q  means  (P ⇒ Q) and (Q ⇒ P).

Example: for any integer n, 6|n ⇔ 2|n and 3|n. Forward: 6|n forces both divisibilities. Reverse: if 2|n and 3|n, coprimality of 2 and 3 gives 6|n. The second half is not implied by the first; it needs its own proof.

“Find all” hides an iffWhenever you list all solutions, you prove both: every actual solution is in the list (necessity) and every listed candidate really works (sufficiency).
04 / LOGICAL PRECISION

Converse, contrapositive, inverse

For P⇒Q, the converse is Q⇒P, the contrapositive is ¬Q⇒¬P, and the inverse is ¬P⇒¬Q.

NameStatementAutomatically equivalent?
OriginalP⇒Q—
Contrapositive¬Q⇒¬PYES
ConverseQ⇒PNO
Inverse¬P⇒¬QNO

To prove “if n² is even then n is even”, prove the contrapositive: if n is odd, write n=2k+1 and calculate n²=4k(k+1)+1, which is odd.

Why the contrapositive is equivalent

P⇒Q fails in exactly one situation: P true and Q false. ¬Q⇒¬P fails in that same situation, so the two are logically equivalent. The converse may have a different truth value.

05 / QUANTIFIERS

For every versus there exists

“For every n there exists m” is not the same as “there exists m for every n”. The first allows m to depend on n; the second demands one m work universally.

∀n∈ℤ ∃m∈ℤ : m>n   is true;  ∃m∈ℤ ∀n∈ℤ : m>n   is false.

To negate “for every n there exists m such that R(n,m)”, write “there exists n such that for every m, R(n,m) is false”. Reverse each quantifier and negate the predicate.

Mathematical statements require the domain: “for all n” without telling us whether n is an integer or real number may be incomplete.

06 / PROOF COMPLETENESS

Cases, equality and edge conditions

A proof by cases needs mutually exhaustive cases. Cases do not have to be disjoint, but if they overlap you must not double count them.

Useful proof-audit questions: Did I divide by a quantity that could be zero? Did I square both sides and admit extraneous solutions? Did I assume all variables were positive when zero is allowed? Did I prove that a bound is reached?

In the Benchmark 3 inequality, equality is not only a=b=c; the zero-coordinate cases matter. That is a logical completeness problem, not merely an algebra problem.

Make a proof audit
  1. Write the domain and exact conclusion.
  2. Underline every “for all”, “there exists”, “only if” or “exactly”.
  3. Check exceptional cases before dividing, taking square roots or cancelling residues.
  4. Separate proof of existence from proof of uniqueness or completeness.
07 / WORKED PRACTICE

Six small logic exercises

  1. Translate “A quadrilateral is cyclic only if its opposite angles are supplementary” into an arrow.
  2. Give a counterexample to “if a number is even, it is divisible by 4”.
  3. Prove for integers n: n is odd iff n² is odd.
  4. Negate “for every real x, there exists y>x with y²>x²”.
  5. Does “if x²=9 then x=3” hold over the reals? Repair it.
  6. Explain both directions required by “find all integer solutions of x²=4”.
Solutions with justification
  1. Cyclic ⇒ opposite angles supplementary. The converse also holds for convex quadrilaterals, but that is a separate statement.
  2. n=2 is even and not divisible by 4.
  3. If n odd, n=2k+1 ⇒n²=2(2k²+2k)+1 odd. If n² odd, n cannot be even since an even square is even.
  4. There exists real x such that for every y>x, y²≤x². This negation is meaningful independently of the original claim’s truth.
  5. No: x=−3. Correct statement: x²=9 ⇒x=3 or x=−3.
  6. Necessity: (x−2)(x+2)=0 ⇒x=±2. Sufficiency: both ±2 square to 4.
EXTENDED WORKSHOP 01 / READ, PROVE, TRANSFER

Necessary versus sufficient in a proof

When to reach for this. A classification often hides two logically separate tasks, and finding a candidate does not prove it is the only one.

Complete worked argument

Consider: an integer n is divisible by 6 if and only if it is divisible by both 2 and 3. To prove 6|n ⇒ 2|n and 3|n, put n=6k. Conversely, if 2|n and 3|n, write n=2a. Since 3|2a and 3 is prime to 2, 3|a. Thus n=6b. Both directions require justification.

The tempting wrong moveSaying “divisible by 2 and 3” is clearly the same as “divisible by 6” may conceal the coprimality condition; for 4 and 6 the corresponding lcm is 12, not 24.

Transfer question

Prove n is divisible by 12 if and only if n is divisible by 3 and 4.

Show a complete answer and proof

If 12|n, both 3 and 4 divide it. Conversely write n=4a. Since 3|4a and gcd(3,4)=1, we have 3|a. Thus n=12b. Both implications are established.

EXTENDED WORKSHOP 02 / READ, PROVE, TRANSFER

Contrapositive versus converse

When to reach for this. The contrapositive has exactly the same truth value as the original implication and is often easier to establish.

Complete worked argument

P⇒Q is equivalent to not Q⇒not P. To prove “if n² is odd, n is odd”, argue contrapositively: if n were even then n=2k and n²=4k² would be even. Therefore n² odd forces n odd. This is not a proof of the converse merely by reversing words.

The tempting wrong moveDo not confuse P⇒Q with Q⇒P. A counterexample to the converse does not contradict the original theorem.

Transfer question

Translate and prove the contrapositive of: if 5 divides n, then 5 divides n².

Show a complete answer and proof

Contrapositive: if 5 does not divide n², then 5 does not divide n. Indeed if 5 divided n, it would divide n²; so not dividing n² excludes divisibility of n.

EXTENDED WORKSHOP 03 / READ, PROVE, TRANSFER

Quantifier order can change the entire question

When to reach for this. When statements involve “for every” and “there exists”, swapping their order changes the strength of the claim.

Complete worked argument

“For every integer n there exists an integer m such that m>n” is true: choose m=n+1 after n is specified. “There exists an integer m such that for every integer n, m>n” is false: taking n=m+1 defeats any fixed m. State variable dependencies explicitly.

The tempting wrong moveA diagram of one chosen configuration cannot prove a claim for every configuration. Likewise a thousand successful examples cannot establish a universally quantified statement.

Transfer question

Negate: For every real x there exists a real y such that x+y>0.

Show a complete answer and proof

The logical negation is: There exists a real x such that for every real y, x+y≤0. The original statement is true, as y=1−x works. The negation is false.

EXTENDED WORKSHOP 04 / READ, PROVE, TRANSFER

Existence, uniqueness and “find all”

When to reach for this. These are separate obligations. Identifying one object proves existence, not uniqueness.

Complete worked argument

To show an equation has a unique real root, show existence (supply and verify a root) and at most one solution (an argument eliminating all others). Example x+3=7 has x=4; subtracting 3 from both sides shows any solution equals 4. The equivalence transformation certifies uniqueness.

The tempting wrong moveDo not conclude a root is unique just because a calculator or graph shows only one visible crossing.

Transfer question

Find all integers n with n(n−1)=0 and explain completeness.

Show a complete answer and proof

The zero-product property gives n=0 or n=1 for any integer solution. Both satisfy the equation. Therefore exactly the two listed integers solve it.

EXTENDED WORKSHOP 05 / READ, PROVE, TRANSFER

Implications in inequalities and equality

When to reach for this. For an extremum problem, proving a bound and proving it is attained are separate directions.

Complete worked argument

For real x, (x−3)²≥0 gives x²−6x+10≥1. This proves that every value of the expression is at least 1. Taking x=3 gives exactly 1. Therefore the minimum is 1, attained only at x=3. Without the equality check, the word minimum would not be established.

The tempting wrong moveAn inequality may be correct but not sharp under the original constraints; do not declare its right-hand side the optimal value without constructing an equality case.

Transfer question

Show the minimum of x²+2x+5 for real x is 4.

Show a complete answer and proof

Complete the square: x²+2x+5=(x+1)²+4≥4. Equality occurs for x=−1. Hence the minimum is 4.

EXTENDED WORKSHOP 06 / READ, PROVE, TRANSFER

Vacuous implication and false premises

When to reach for this. A conditional statement P⇒Q is true when P is false; this matters for proving and disproving statements.

Complete worked argument

“If a natural number is less than zero, then it is even” is logically true under the convention natural numbers are nonnegative; there is no counterexample with a true premise. To refute a universal implication you must find an instance where P is true and Q false.

The tempting wrong moveTo disprove P⇒Q, do not provide a case where both P and Q are false. That is not a counterexample.

Transfer question

Is the claim “if an integer is divisible by 4, then it is divisible by 2” false because 3 is neither?

Show a complete answer and proof

No. The integer 3 fails the premise and cannot disprove the implication. For any integer n=4k, write n=2(2k), so the implication is true.
